上游与协议路由

anonymous 会耗尽可用 Proxy；显式 protocol 映射优先于模型名称推断。
这是所有模型对外的上下文窗口，默认 160000。/v1/models 的 context_window / context_length 与 metadata 都按它声明，客户端因此按 160k 规划并压缩自己的对话历史；模型自身窗口更小的仍保留更小值。 万一客户端不理会上限、把更长的历史发上来，网关在本机直接返回 413 （context_length_exceeded），请求不会发到上游——上游一旦看到超过 200k 的上下文就会封禁出口 IP。

免费模型 WARP 出口

开启后，免费通道（匿名、免费模型回退、可用性探测、匿名模型目录刷新）改走用户态 Cloudflare WARP 隧道，不再使用任何代理，上游看到的是 WARP 出口地址。进程内完成 WireGuard 握手与用户态网络栈终结，不需要 TUN、root 或改路由表，但宿主机必须能向 Cloudflare 端点发送 UDP（端口 2408）。Go Key 与付费模型仍走原代理。
这是失败即拒绝的开关：WARP 初始化不成功时会拒绝保存并保持原有运行时，不会静默回退到代理。
上游免费额度按出口网段计算：每个出口从该前缀绑定自己的源地址，替换出口才会真正换到新网段。 需要 warp.stack 为 ipv6；留空则共用本机默认源地址。前缀需路由到本机 （Linux 下网关会用 IPV6_FREEBIND 绑定）。

会话隔离

每个下游会话（客户端会话头，或按调用方 Key 隔离的首条消息指纹）映射到独立的上游会话，防止并发对话在上游串台。空闲超过 TTL 后下一轮会开启新的上游会话（对话历史在请求体里，正确性不受影响，仅损失一次缓存命中）。

SOTA / 甜点模型轮转

成功后继续使用当前模型。额度不足或错误时按顺序切换，仅使用 OpenCode Go。

沿用现有 Base URL 和 API Key，将 OPENAI_MODEL 设为下方别名。每个模型普通错误最多尝试 3 次，一次请求最多重试 3 个模型；额度不足直接跳过。
